# 手表端单 APK、adb 导入、零网络

这是一个个人使用的 Galaxy Watch4 Classic 离线 GPX 导航应用。应用只以单 APK 形式侧载在手表上，不提供手机伴侣，也不上架商店；GPX 在出发前由 adb 推送到手表的导入目录，导航期间不申请 INTERNET 权限、不发起网络请求。这样把双端数据层、网络权限和商店审核排除在 v1 之外，代价是加新路线必须回到电脑，徒步现场无法导入。未来若增加现场导入，可以在不改路线库与导航模型的前提下增加表端 Wi-Fi 上传页或手机伴侣。

> 2026-10-23 更新：导入通道已扩展为 adb + 局域网上传页，应用为此申请 INTERNET 权限（仅用于本地监听，不发起外网请求）；因此原文中“只走 adb 导入、不申请 INTERNET 权限”的表述已被取代，导航期间仍然零网络。见 ADR-0004。
