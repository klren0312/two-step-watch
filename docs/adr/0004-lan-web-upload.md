# 局域网上传页作为第二导入通道

为了让没有电脑或数据线的场景也能导入 GPX，手表应用在“网页导入”页临时启动一个仅监听局域网的 HTTP 服务：随机 token 放在地址中，只接受 multipart 的 `.gpx` 文件、单文件上限 20 MB，上传后自动解析入库，离开该页面立即停服；手机与手表需连同一 Wi-Fi。adb 导入继续保留。代价是应用新增 INTERNET 权限（只用于本地监听，不发起外网请求），并依赖手表 Wi-Fi 与上传期间的屏幕常亮；地址含一次性 token，但仍是明文 HTTP，只应在可信局域网使用。导航期间的零网络特性不变。
